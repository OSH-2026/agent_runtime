# 示例

- android-action-runtime：Android 应用示例，在前台服务中运行 Kotlin Action Runtime。
- dispatcher_demo：Rust 示例，运行 dispatcher 并使用本地 echo action 验证 DAG 调度。
- tauri-workflow-android：Tauri 2 Android 应用，输入 ActionFlow YAML 并通过 Rust dispatcher 执行。
- tauri-chatbot-android：Tauri 2 Android chatbot，自动执行模型返回的 ActionFlow YAML，并将结果循环反馈给模型。
