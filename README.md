```
OSH-26/
```

## 会议记录

组会纪要集中在此，便于新成员对齐背景；后续会议将按时间顺序续写。

| 次序 | 日期 | 主题与结论摘要 |

| 1 | 2026-03-09 | **组队与方向摸底**：完成成员组队，交流各自兴趣与课程要求，对齐 OSH 大作业预期；初步划定「移动 / 系统 + 智能体」相关的大方向，未锁定具体技术栈。 |

| 4 | 2026-04-10 | **组内分工**：同步近期文档与实验进展；将工作拆成两条并行线——**Model Framework 组**（模型侧、端侧推理与评测相关）与 **Action Fabric 组**（结构化工具调用、高性能工具调度），后续在接口与里程碑上定期对齐。 |
| 5  | 2026-04-15 | **与指导老师讨论：从工具调用链切入 Action Fabric**：在前期方向基础上进一步收敛技术路径，明确以 **工具调用链（Tool Invocation Chain）** 为核心切入点，在实现结构化 Action 对象的基础上，通过 DAG 来结构化地表达任务流程，实现 Action 执行和模型推理的解耦，用图调度策略助力 Agent 更加高效地完成工具调用|
