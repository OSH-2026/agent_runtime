```
OSH-26/
├── src/          # 源代码目录
```

## 会议记录

组会纪要集中在此，便于新成员对齐背景；后续会议将按时间顺序续写。

| 次序 | 日期 | 主题与结论摘要 |

| 1 | 2026-03-09 | **组队与方向摸底**：完成成员组队，交流各自兴趣与课程要求，对齐 OSH 大作业预期；初步划定「移动 / 系统 + 智能体」相关的大方向，未锁定具体技术栈。 |

| 4 | 2026-04-10 | **组内分工**：同步近期文档与实验进展；将工作拆成两条并行线——**Llama 组**（模型侧、端侧推理与评测相关）与 **Agent Runtime 组**（运行时、任务流与系统能力编排），后续在接口与里程碑上定期对齐。 |
| 5  | 2026-04-15 | **与指导老师讨论：从工具调用链切入 Agent Runtime**：在前期方向基础上进一步收敛技术路径，明确以 **工具调用链（Tool Invocation Chain）** 为核心切入点，围绕任务在 Runtime 中的执行流程（解析 → 规划 → 调用 → 反馈 → 迭代）展开设计；强调对调用过程的可观测性与可复现性，作为系统实现与评测的主线。 |
